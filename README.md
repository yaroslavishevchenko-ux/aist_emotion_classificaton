# Emotion Classification on AIST Dataset

Воспроизведение и улучшение моделей для многоклассовой классификации эмоций в коротких русскоязычных сообщениях неформального интернет‑общения.  
Используется открытая часть датасета **AIST** (50 750 сообщений, 5 эмоций: neutral, joy, sadness, anger, uncertainty).

## Структура репозитория

- `emotion_detection.ipynb` – основной Jupyter ноутбук с загрузкой данных, EDA, обучением и анализом ошибок всех моделей  
- `report.pdf` – итоговый отчёт (структура: введение → обзор литературы → модели → данные → эксперименты → выводы)  
- `README.md` – текущий файл  

## Результаты

Сводная таблица Macro F1 для всех экспериментов (стратифицированный сплит 80/20, random_state=42).

| Модель | Macro F1 |
|--------|----------|
| fastText CC + LogReg (baseline) | 0.7162 |
| fastText CC + LogReg + balanced | 0.7157 |
| fastText CC + POS + LogReg | 0.7257 |
| fastText CC + POS + LogReg + пороги | 0.7256 |
| CatBoost (fastText+POS) | 0.7737 |
| CatBoost + fastText+POS+rubert | 0.7660 |
| CatBoost стек (CC+POS+AIST) | 0.7774 |
| **rubert-tiny2 fine-tuned** | **0.8348** |
| BERT + CatBoost ансамбль | 0.8348 |

Лучший результат – **fine‑tuned rubert‑tiny2 (Macro F1 = 0.8348)** – превосходит оригинальную статью (0.81) на 2.5 п.п., несмотря на использование лишь половины полного датасета.

## Основные выводы

**Положительный результат:**  
Дообучение лёгкого трансформера `rubert-tiny2` без ансамблирования и специальных лингвистических признаков позволило превзойти как baseline на статических эмбеддингах, так и лучший опубликованный результат для AIST.

**Отрицательный результат:**  
- Взвешивание классов не дало прироста – классы практически сбалансированы.  
- Калибровка порогов не улучшила LogReg – вероятности модели уже хорошо откалиброваны.  
- Замороженные эмбеддинги `rubert-tiny2` в CatBoost ухудшили качество – контекстные векторы внесли шум.  
- Ансамбль BERT + CatBoost не дал дополнительного выигрыша.

**Вклад:**  
- Сравнение классических ML‑методов, градиентного бустинга и лёгких трансформеров для русского датасета AIST.  
- Эффективный стекинг эмбеддингов (Common Crawl + POS + AIST‑fastText), давший +6.1 п.п. к baseline без использования нейросетей.  
- Анализ, показывающий, что трансформер особенно улучшает распознавание ранее проблемных классов neutral и joy.  
- Документированные случаи неэффективности популярных техник с объяснением причин.
